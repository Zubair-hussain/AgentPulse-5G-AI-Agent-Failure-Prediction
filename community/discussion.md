# Discussion draft (publish once, after release)
**Can agent failure be predicted from runtime telemetry alone?**

I built AgentPulse to explore whether latency, retries, context usage and other numerical signals predict simulated AI-agent failures. The 20k synthetic demo has a held-out logistic ROC-AUC of 0.765. It's not production evidence; I'm particularly interested in where the simulator falls short. What real telemetry signals would you add, and what validation protocol would you trust? Contributions and reproducible counterexamples welcome. Add the verified published link before posting on Hugging Face/Kaggle/GitHub Discussions. Avoid repetitive cross-posting.
